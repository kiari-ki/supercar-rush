# 超跑狂飙 · SUPERCAR RUSH 🏎️

一个纯前端 HTML5 Canvas 赛车竞速小游戏，零依赖，单文件实现。

## 玩法

- 打开 `index.html` 或访问在线地址即可开始游戏
- 方向键 / WASD 控制赛车左右移动与加减速
- 收集氮气、躲避车流，尽可能跑得更远、得分更高

## 技术栈

- 原生 HTML + CSS + JavaScript
- HTML5 Canvas 渲染
- 无任何第三方依赖，无需构建

## 本地运行

直接用浏览器打开 `index.html` 即可，无需安装任何东西：

```
index.html
```

## 部署

这是一个纯静态站点，可以一键部署到任意静态托管平台：

- **Vercel**：导入 GitHub 仓库后，Framework Preset 选 "Other"，无需配置构建命令，直接部署即可
- **GitHub Pages**：仓库 Settings → Pages → 选择 main 分支根目录
- **Netlify**：拖拽上传或连接仓库均可
